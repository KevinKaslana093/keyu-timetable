# 课屿 1.1.3 页面兼容修复体验版

修复旧读取器对 DOM 节点集合迭代器和 NodeList.forEach 的依赖，改用按索引复制。旧版可能在统计星期标题时抛出异常，并错误显示 blockedFrames=1、weekdayCells=0、cards=0，实际上还未开始提取课程。

分离“跨域文档访问失败”和“读取程序错误”，诊断失败也不会阻止提取或框架遍历。新版诊断增加错误阶段与错误类型，不复制错误原文或个人内容。

已在虚构浏览器页面复现旧版误报并验证新版能导入。尚不能凭旧版诊断证明用户设备上的根因完全相同，真实学校页面仍待更新后重试。

可直接覆盖安装保留课表。网页内页打开、PDF 导入和两套校区作息继续保留。

验证：13 项单元测试、Chrome 旧/新版兼容对照及 Android 15 完整导入流程通过。测试记录：https://github.com/KevinKaslana093/keyu-timetable/actions/runs/34857917916
