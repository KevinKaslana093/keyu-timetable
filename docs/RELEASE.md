# 课屿 1.0.0 体验版

导入每个人自己的课表文件，在本地生成周课表和实际日期课程安排。

支持华工教务文字版 PDF、标准七列 XLSX / CSV / HTML、课屿 JSON 备份；包含课程编辑、单双周、调休、搜索、多课表和 ICS 导出。

使用前请核对第 1 周周一日期与校区节次时间。默认作息是示例，不能直接视为学校正式作息。未指定节次的实践课保留为事项，不自动安排课程通知。

Android 提醒受通知权限、精确闹钟权限和厂商后台策略影响。iOS 和原生 HarmonyOS 使用浏览器版；本次不提供原生 iOS / 鸿蒙包。各品牌真机适配仍需测试，不做全部机型兼容承诺。

数据仅保存在当前设备；更新或换机前建议导出 JSON。公开示例不包含真实个人课表。
