# 课屿 1.1.2 内嵌课表读取体验版

针对诊断中“仅读到外层页面、一个跨域内页、无星期标题或课程块”的情况，新增“打开课表内页”：保留当前登录状态打开可见的学校内页，再确认学期并点击读取。仅允许经过校验的学校地址，不关闭浏览器跨域保护，不向学校页面提供本机数据接口。

诊断只包含结构数量与内页来源，不包含地址中的路径、查询参数、账号、密码或课程内容。无法识别的页面仍可使用 PDF 导入。

沿用原包名与签名，可覆盖安装保留课表。真实学校页面尚待用户重试，测试使用虚构页面，不代表全部校区和手机已完成真机验证。

验证：11 项单元测试、Chrome 跨域虚构页面和 Android 15 完整导入流程通过。测试记录：https://github.com/KevinKaslana093/keyu-timetable/actions/runs/34814445135
