# 课屿 1.1.0 体验版

新增 Android 应用内华工教务导入：学校页面登录 → 查询个人课表并切换表格 → 读取 → 核对保存。此功能处于实验阶段，真实账号与校园网流程仍待验证；失败时可用原有 PDF 导入。

新增五山、大学城 / 国际校区完整 11 节作息，导入预览和设置页均可选择，自动用于课表、提醒和 ICS。也可手动修改。旧课表时间不会自动更换。

支持保存的华工教务表格 HTML 导入，继续支持 PDF / 标准七列 XLSX、CSV、HTML / JSON。

使用原有包名与签名，可直接覆盖 1.0.0，建议先导出 JSON 备份。新增联网权限只为学校网页；课表本身仍可离线使用。学校统一认证使用 HTTPS，教务站点由学校重定向为 HTTP，关闭导入页后清除该应用中的登录会话。

iPhone、原生鸿蒙继续使用网页版及 PDF 导入，本版不提供 IPA/HAP。各品牌后台提醒、真实账号导入仍需真机验证。
